# FleetLedger design commitment

- **Use context:** long office sessions plus occasional workshop/mobile checks.
- **Theme:** light by default; complete dark override supported.
- **Accent:** one amber hue (`38°`) because the product must feel like practical operational work. Hover/active/tint states derive from the same hue.
- **Neutrals:** nine warm-tinted steps; no pure black/white.
- **Spacing:** 4px grid.
- **Radius:** one 12px token.
- **Shadow:** one restrained token.
- **Type:** system UI stack; body remains at least 16px.
- **Shell:** persistent desktop sidebar; four-item bottom navigation below 768px.
- **Tables:** 5–6 decision columns; mobile cards expose identifier, status, vendor/bus and amount.
- **Forms:** labels never placeholders; money fields use decimal input mode; the long bill form is a full page and autosaves locally.
